## 0. 한 줄 요약 (기획 공식)

> **자극 나레이션 훅(행동 장면 위) → 권위자(정찬성)의 원본 리액션으로 훅 증명 → 주인공 썰(원본 대화, 문장마다 컷) → 나레이션으로 장면 전환 "그리고 ○○와의 경기가 시작되는데" → 스파링(원본 현장음 + 상황 캡션) → 나레이션 "진지모드" 반전 → 주인공 고전(원본 대사) → 나레이션 교훈형 마무리 "~는 국룰인가 봅니다"**

나레이션은 다음 다섯 곳에만 들어간다. 나머지는 모두 원본 소리다.

| 위치 | 시간 | 나레이션 | 역할 |
|---|---|---|---|
| 오프닝 | 0.2–2.5초 | 주먹으로 교도소를 평정했다는 / 일반인 도전자인데 | 훅: 가장 자극적인 설정 |
| 썰 브리지 | 8.9–10.4초 | 그리고 자신의 영웅담을 얘기하는데 | 대화 파트로 넘김 |
| 본론 진입 | 22.1–24.0초 | 그리고 저승문호와의 경기가 시작되는데 | 장소·상황 전환 |
| 반전 | 32.0–34.7초 | 생각보다 잘치는 도전자에게 진지모드로 들어가는데 | 긴장 상승, 반전 예고 |
| 엔딩 | 41.7–44.2초 | 강자를 만나고 눈빛이 바뀌는건 국룰인가 봅니다 | 교훈·드립형 마무리 |

**나레이션 문장 패턴 [확인]:** 모든 나레이션이 "~했다는 / ~인데 / ~는데 / ~에게 / ~는건"처럼 **문장을 끝맺지 않는 연결어미**로 끝나고, 바로 다음 원본 클립이 그 문장을 이어받는다. 마지막 문장만 "~봅니다"로 닫는다.

## 1. 화면 레이아웃 (전 구간 고정) [확인]

```
y=0     ┌──────────────────────┐
        │   검정 여백 (253px)    │
y=253   │ 저승문호에게 도전하는     │  제목 1줄 (높이 약 82px)
y=352   │ 교도소 대장출신 일반인    │  제목 2줄 (높이 약 82px)
y=480   ├──────────────────────┤
        │                      │
        │  영상 영역 1080x960     │  원본을 가로 1080에 맞춰 9:8 비율로 크롭
        │  (자막·캡션은 이 안에)    │
y=1440  ├──────────────────────┤
        │   검정 여백 (480px)    │  아무것도 없음
y=1920  └──────────────────────┘
```

- **제목 (44초 내내 고정, 애니메이션 없음)**
  - 1줄: `저승문호에게`는 **노랑**, ` 도전하는`은 **흰색**
  - 2줄: `교도소 대장출신`은 **빨강**, ` 일반인`은 **흰색**
  - 굵은 고딕, 검정 외곽선, 가운데 정렬. 핵심 단어 두 개(대결 상대, 주인공의 자극 설정)만 색을 바꿈
- **영상 영역:** 원본 16:9 영상을 9:8로 잘라 인물 위주로 크게 보이게 함. 컷마다 크롭 위치와 확대율이 다름(아래 표 참고)
- **색감 필터 [확인]:** 전체 영상에 강한 샤프닝과 디테일·대비 강조가 걸려 있어 그림처럼 보이는 질감. 모든 컷에 똑같이 적용

## 2. 자막 스타일 규칙 [확인]

| 종류 | 모양 | 위치 | 쓰는 곳 |
|---|---|---|---|
| **A. 나레이션 자막** | 흰 글씨, 검정 외곽선, 박스 없음. 핵심 단어 1개만 **빨강** (예: `주먹으로`, `영웅담을`, `시작되는데`, `진지모드로`) | 영상 영역 가운데보다 약간 아래 (y≈1070) | 나레이션 |
| **B. 원본 대사 자막** | **빨간 글씨 + 반투명 어두운 박스** | 영상 하단부 (y≈1240 근처, 컷마다 조금씩 다름) | 출연자 대사 대부분 |
| **B'. 원본 대사(흰색)** | 흰 글씨, 박스 없음 (A와 같은 모양이지만 빨간 강조 없음) | A와 같은 위치 | 일부 원본 대사: "거기서 최고였다 ??", "쿳찮디 그냥 한대", "팍 주면은", "박문호도 맞출 수 있을꺼라고", "혹시 생각하나요 ??" |
| **C. 감정 캡션 (빨강)** | 괄호 + 빨간 글씨 + 박스 | 대사 자막 자리 또는 화면 위쪽 | (집중) (확신) (자신만만) (아쉽) (퍽) |
| **C'. 감정 캡션 (초록)** | 괄호 + **초록** 글씨 + 검정 외곽선, 박스 없음 | 화면 **오른쪽 위** 또는 인물 머리 위 | (감탄) (휘청) |

| **D. 현장 리액션** | 큰따옴표 + 흰 글씨 `" 우와 "` | 화면 가운데 | 구경꾼 감탄 |
| **E. 상황 설명 (음성 없음)** | A와 같은 모양 | A와 같은 위치 | "이어지는 스파링": 나레이션 목소리 없이 글자만 나옴 |

## 3. 오디오 구조

- **나레이션 목소리 [확인]:** 낮은 남성 톤(기본 음높이 약 90~110Hz), 억양 변화가 적은 일정한 톤. TTS일 가능성이 높음 [추정]. 위 다섯 구간에서만 나오고, 음색이 모든 나레이션 구간에서 같음(유사도 0.65~0.87)
- **원본 목소리 [확인]:** 정찬성 대사는 나레이션과 음색이 뚜렷하게 다름(정찬성끼리 유사도 0.82~0.95, 나레이션과는 −0.3~−0.5)
- **배경 지속음 [확인/추정]:** 약 500Hz 부근에 끊기지 않는 지속음이 **영상 처음부터 끝까지** 깔려 있음. 대화 구간(3초 전후, 12~16초, 30초, 41초)에서 크고, 스파링 구간(24~29초)에서는 현장음에 묻혀 작음. 사용자가 들은 "위웅" 효과음이 이 소리로 보임 [추정]. 정확한 음원 이름은 [미확인]
- **효과음 [미확인]:** 소리를 직접 들을 수 없어서 정확한 효과음 종류는 특정하지 못함. 화면 캡션 (퍽)(대포소리)(휘청)이 붙은 지점이 타격음이나 효과음 후보
- **전체 음량:** −8.1 LUFS (쇼츠 기준으로 꽤 크게 마스터링)
